# 雷管数据记录规范

每一发进入检测线的雷管，在终判完成后生成 **一条完整记录**，用于质量追溯、产能统计与问题复盘。

## 1. 存储位置

| 类型 | 路径 | 说明 |
|------|------|------|
| 主记录 CSV | `logs/results.csv` | 追加写入；程序启动自动建表头 |
| NG 图像 | `logs/ng_images/` | 不合格时保存（配方 `save_ng_image=true`） |
| 样例 | `doc/samples/detonator_records_sample.csv` | 文档用示例，非运行时写入 |

运行时由 `app/line/ResultTrace` 落盘；内存结构见 `app/core/ProductRecord.h`。

## 2. CSV 字段（v1）

编码：UTF-8。分隔符：逗号。文本字段必要时用双引号包裹。

| 列名 | 类型 | 单位/取值 | 说明 |
|------|------|-----------|------|
| `time` | string | ISO8601 | 终判时间 |
| `slot` | uint | — | 工位槽位号（对号键） |
| `seq` | uint | — | 产品流水号 `ProductSeq` |
| `recipe_id` | int | — | 判定所用配方 ID |
| `pass` | 0/1 | — | 1=合格，0=不合格 |
| `fail_code` | uint | 见下表 | 不合格原因码 |
| `fail_reason` | string | — | 可读原因 |
| `d1_mm` | float | mm | 端 A 外径 |
| `d2_mm` | float | mm | 端 B 外径 |
| `od_ok` | 0/1 | — | 外径工位算法是否成功 |
| `od_ms` | int | ms | 外径算法耗时 |
| `length_mm` | float | mm | 长度 |
| `length_ok` | 0/1 | — | 长度工位算法是否成功 |
| `length_ms` | int | ms | 长度算法耗时 |
| `defect_grade` | int | 0~N | 瑕疵等级，0 最好 |
| `defect_count` | int | — | 检出缺陷块数量 |
| `defect_ok` | 0/1 | — | 瑕疵工位算法是否成功 |
| `defect_ms` | int | ms | 瑕疵算法耗时 |
| `defect_summary` | string | — | 瑕疵摘要 |
| `ng_image` | string | 路径或空 | NG 存图相对/文件名 |

## 3. 故障码 `fail_code`

与 `config/plc_points.json` → `fail_codes` 及写回 PLC 的 `FailCode` 一致：

| 码 | 名称 | 含义 |
|----|------|------|
| 0 | None | 合格或未判定失败 |
| 1 | OdOutOfTol | 外径超差 |
| 2 | LengthOutOfTol | 长度超差 |
| 3 | Defect | 瑕疵等级超限 |
| 4 | TimeoutMissing | 缺工位结果或超时 |
| 5 | AlgoError | 算法失败 |
| 6 | CommError | 通信异常 |
| 7 | Unknown | 未分类 |

## 4. 判定规则（写入记录前）

配方默认见 `config/recipes/default.json`：

```
Pass =
  三工位 ready 且 algo_ok
  AND |D1 - d_nom| ≤ d_tol  AND |D2 - d_nom| ≤ d_tol
  AND |L - l_nom| ≤ l_tol
  AND defect_grade ≤ max_defect_grade
```

任一条不满足则 `pass=0`，并填入对应 `fail_code` / `fail_reason`。

## 5. 与内存对象对应关系

| CSV | `ProductRecord` |
|-----|-----------------|
| `slot` | `slot` |
| `seq` | `productSeq` |
| `d1_mm` / `d2_mm` | `od.d1Mm` / `od.d2Mm` |
| `length_mm` | `length.lengthMm` |
| `defect_grade` | `defect.grade` |
| `pass` / `fail_code` | `pass` / `failCode` |

## 6. NG 图像约定

- 文件名：`NG_slot{槽位}_seq{流水}_{时间戳}.raw`
- 内容：首行 `宽 高 通道`，其后为连续 BGR8 字节  
- 优先保存瑕疵工位帧，其次外径、长度帧
